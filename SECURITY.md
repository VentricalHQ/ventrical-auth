# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not file public issues, pull requests or discussions for them.

You can report in either of these ways:

- Email: ventrical.contact@ventricalhq.com
- GitHub private vulnerability reporting: open the repository's Security tab and choose "Report a vulnerability".

Please include:

- A description of the vulnerability and its impact.
- The affected version (or commit) and your environment (Node version, adapter, store).
- Steps to reproduce, ideally a minimal proof of concept.
- Any suggested fix or mitigation, if you have one.

Do not include real credentials, tokens or personal data in a report.

## Supported versions

This package is experimental. Only the latest 0.0.x release is supported.

## What to expect

Reports are handled on a best-effort basis. There is no bug bounty, and no response time is promised.
